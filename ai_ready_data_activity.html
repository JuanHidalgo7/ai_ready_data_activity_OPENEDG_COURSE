From Raw Files to AI-Ready Data

Interactive class activity for Lesson 1: Python Data Ingestion and Basic Cleaning

Activity Overview

Goal: Practice how raw files become clean, organized, AI-ready data. You will identify file types, find data problems, simulate cleaning steps, order a basic data workflow, explore JSON data, and complete an AI readiness check.

Artificial Intelligence depends on data. Before data can be used for analysis or model training, it must be loaded, inspected, cleaned, organized, and saved. This process is called data ingestion and preparation.
